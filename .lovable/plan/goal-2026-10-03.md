## Goal

Improve load speed and scrolling smoothness while preserving the portfolio’s current visual design.

## Changes

**Image delivery**
- Convert the large transparent profile portrait to a substantially smaller modern image format.
- Keep transparency, visual quality, dimensions, and the existing portrait composition intact.

**Touch and mobile behavior**
- Disable mouse-follow tilt, glare, and cursor-wave calculations on touch or coarse-pointer devices.
- Keep all tiles fully usable and visually polished without motion-dependent interactions.
- Apply the same gating to the profile portrait and floating tool logos.

**Animation workload**
- Pause or avoid decorative motion when sections are outside the viewport.
- Reduce unnecessary always-running background animation and respect reduced-motion preferences.
- Make the navigation scroll listener passive.

**Verification**
- Check desktop and mobile layouts, interaction behavior, image rendering, console output, and the current app build.

## Technical notes

The optimization will reuse the shared tilt wrapper, pointer capability checks, viewport-aware animation controls, and a compressed transparent WebP portrait.
